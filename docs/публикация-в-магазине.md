# Публикация в Chrome Web Store

Пакет собирается командой `node scripts/собрать-для-магазина.js` — получается
`build/videolov-<версия>.zip`. Всё остальное выполняется вручную: загрузка в
магазин требует входа в аккаунт Google, единовременного взноса и подтверждения
личности, а эти действия нельзя выполнить за владельца аккаунта.

Ниже — порядок действий и готовые тексты для полей формы.

## 1. Регистрация разработчика

1. Откройте <https://chrome.google.com/webstore/devconsole>.
2. Войдите под аккаунтом Google, на который будет оформлено расширение.
3. Оплатите единовременный взнос **5 долларов** (списывается один раз, не за
   каждое расширение).
4. Заполните профиль разработчика: имя, публикуемое в карточке, и почта для
   связи. Почта подлежит подтверждению.

## 2. Загрузка пакета

1. **New item** → перетащите `build/videolov-1.0.0.zip`.
2. Дождитесь разбора манифеста. Расширение получит **идентификатор** — он
   виден в адресе страницы и в разделе Package.

## 3. Обязательный шаг после публикации

Опубликованное расширение получает **другой идентификатор**, не тот, что у
распакованного. Локальный загрузчик пускает к себе только известные ему
расширения, поэтому:

1. Откройте `helper/allowed-extensions.json`.
2. Добавьте выданный магазином идентификатор в список `ids`.
3. Запустите `helper/установить.bat` заново.

Без этого шага расширение из магазина не увидит загрузчик и сообщит, что он
недоступен.

```

**Полное описание**

```
Видеолов находит видео на открытой странице и сохраняет его на диск в исходном
качестве.

ВОЗМОЖНОСТИ

• Обнаружение потоков HLS и DASH, а также прямых видеофайлов
• Формат определяется по содержимому, а не по расширению в адресе — работают и
  нестандартные адреса, которые другие расширения пропускают
• Выбор качества из списка, доступного в потоке
• Три режима: видео со звуком, только звук (m4a, mp3, opus), только видео
• Кадр из середины ролика в списке — видно, какой именно материал сохраняется
• Прогресс, скорость, оставшееся время, отмена
• История загрузок с быстрым переходом к файлу
• Имя файла из заголовка страницы, раскладка по папкам источников

ЗАКРЫТЫЕ ПЛОЩАДКИ

Cookie активной вкладки передаются загрузчику, поэтому материалы, доступные вам
по подписке или по учётной записи, сохраняются без дополнительной авторизации.

СКОРОСТЬ

Фрагменты потока загружаются параллельно — до 32 соединений. Скорость
ограничена только вашим каналом.

ЧТО ТРЕБУЕТСЯ

Загрузку выполняет отдельный компонент, который устанавливается на компьютер
один раз: Node.js, yt-dlp и ffmpeg — все бесплатные и с открытым кодом.
Инструкция: https://github.com/novnik25/videolov

КОНФИДЕНЦИАЛЬНОСТЬ

Расширение не собирает статистику и не обращается ни к каким серверам, кроме
тех, с которых вы сохраняете видео. Исходный код открыт.

ОГРАНИЧЕНИЕ

Видео с защитой DRM (Widevine) сохранить нельзя — это ограничение технологии.

Сохраняйте только те материалы, к которым у вас есть правомерный доступ.

## 5. Обоснование разрешений

Раздел **Privacy practices** — то место, где заявки чаще всего отклоняют.
Каждое разрешение требует объяснения; формулировки ниже готовы к вставке.

| Поле | Текст |
| --- | --- |
| **Single purpose** | Обнаружение видео на открытой странице и его сохранение на диск пользователя. |
| `webRequest` | Наблюдение за сетевыми запросами вкладки, чтобы обнаружить адрес видеопотока. Запросы не изменяются и не блокируются. |
| `cookies` | Чтение cookie сайта, с которого пользователь сохраняет видео, чтобы загрузка выполнялась от его имени и материалы по подписке были доступны. |
| `tabs` | Определение активной вкладки и её заголовка — для привязки найденного видео к вкладке и формирования имени файла. |
| `storage` | Хранение настроек пользователя и истории загрузок на его компьютере. |
| `nativeMessaging` | Передача задания локальному загрузчику, установленному пользователем на своём компьютере. |
| **Host permissions** | Видео может встретиться на любом сайте, поэтому заранее ограничить список доменов невозможно. Расширение обращается только к тем адресам, которые пользователь выбрал для загрузки. |
| **Remote code** | Нет. Весь код входит в пакет; внешние скрипты не загружаются и не выполняются. |
| **Data usage** | Отметьте «не собираются» по всем категориям. Расширение не передаёт данные никуда, кроме локального компонента на компьютере пользователя. |

## 6. Чего ожидать от проверки

- **Срок.** От нескольких дней до двух недель. Расширения с широким доступом к
  сайтам проверяются дольше.
- **Вероятные вопросы.** Требование обосновать доступ ко всем сайтам и запрос
  демонстрации работы. Отвечайте ссылкой на репозиторий: открытый код снимает
  большую часть вопросов.
- **Риск отклонения.** Магазин настороженно относится к средствам сохранения
  чужого содержимого. Подчеркните назначение: доступ к материалам, которые
  пользователь уже оплатил или получил правомерно. Похожие расширения в
  магазине присутствуют, то есть само назначение допустимо.
- **Внешний компонент.** Требование установить программу на компьютер
  допустимо, но должно быть заявлено в описании — в тексте выше это сделано.

## 7. Снимки экрана

Требуется не менее одного снимка размером **1280×800** или **640×400**.
Подготовленные лежат в `docs/магазин/`.

## 8. Обновление версии

1. Поднимите `version` в `extension/manifest.json`.
2. Соберите пакет заново и загрузите его в разделе Package.
3. Обновление проходит ту же проверку, обычно быстрее первой.
