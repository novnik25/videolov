# Видеолов

Расширение для браузера, которое находит видео на открытой странице и сохраняет
его на диск в исходном качестве.

Работает с потоковым видео (HLS, DASH) и прямыми файлами, в том числе на
закрытых площадках, куда вы вошли под своей учётной записью. Скорость загрузки
ограничена только вашим каналом: фрагменты потока загружаются параллельно.

Бесплатно, с открытым исходным кодом, без рекламы и без передачи данных
на сторонние серверы.

![Окно расширения](docs/окно-выбор-качества.png)

## Возможности

| | |
| --- | --- |
| **Автоматическое обнаружение** | Потоки HLS и DASH, прямые файлы. Формат определяется по содержимому, а не по расширению в адресе — распознаются и нестандартные адреса вида `/api/playlist/master/<id>` |
| **Закрытые площадки** | Cookie активной вкладки передаются загрузчику, поэтому материалы, доступные вам по подписке, сохраняются без дополнительной авторизации |
| **Выбор качества** | Список доступных разрешений читается из манифеста потока за доли секунды |
| **Три режима** | Видео со звуком, только звук (m4a / mp3 / opus), только видео |
| **Предпросмотр** | В списке показывается кадр из середины ролика — видно, какой именно материал сохраняется |
| **Управление загрузками** | Прогресс, скорость, оставшееся время, отмена, история с быстрым доступом к файлу |
| **Именование и раскладка** | Имя берётся из заголовка страницы и правится перед стартом; файлы раскладываются по папкам источников |

Известные площадки — YouTube, VK, Rutube, Vimeo, Дзен, OK, Twitch, TikTok —
обрабатываются по адресу страницы: корректное название, автоматическая склейка
видео и звука.

**Ограничение:** видео с защитой DRM (Widevine) сохранить нельзя — поток
зашифрован ключом, недоступным за пределами защищённого модуля браузера. Это
ограничение технологии, а не программы.

## Как устроено

Расширение не загружает данные само — оно находит поток и передаёт задание
локальному компоненту, который работает на вашем компьютере.

```
Страница                браузер запрашивает поток
   │
   ▼
Расширение              находит видео, собирает адрес, cookie и заголовки
   │
   ▼
Локальный загрузчик     yt-dlp + ffmpeg, параллельная загрузка фрагментов
   │
   ▼
Готовый файл            mp4 или m4a в выбранной папке
```

Связь между браузером и загрузчиком — механизм native messaging: браузер
запускает компонент по запросу и завершает после использования. Сетевых портов
не открывается, фоновых служб не остаётся, обращаться к загрузчику может только
это расширение.

**Данные никуда не передаются.** Ни адреса, ни cookie, ни статистика
использования не покидают компьютер. Расширение не обращается ни к каким
серверам, кроме тех, с которых загружается выбранное вами видео.

## Установка

Требуются три бесплатных компонента:

```
winget install OpenJS.NodeJS yt-dlp.yt-dlp Gyan.FFmpeg
```

Затем:

1. **Локальный загрузчик** — запустите `helper\установить.bat`.
   Компонент копируется в `%LOCALAPPDATA%\Videolov` и регистрируется для
   Chrome, Chromium, Edge и Яндекс.Браузера. Установщик проверяет
   работоспособность запуском и сообщает результат.
2. **Расширение** — откройте `chrome://extensions` (в Яндекс.Браузере —
   `browser://extensions`), включите **режим разработчика** и нажмите
   **«Загрузить распакованное расширение»**, указав папку `extension`.
3. Перезапустите браузер, если он был открыт.

Готово, если в заголовке окна расширения горит зелёный индикатор
**«загрузчик готов»**.

Удаление: `helper\удалить.bat` и удаление расширения на странице расширений.

## Использование

1. Откройте страницу с видео и запустите воспроизведение.
2. Нажмите значок расширения — найденные материалы появятся в списке.
3. Разверните карточку, при необходимости измените имя файла и качество.
4. Нажмите **«Скачать»**.

Если список пуст, обновите страницу: плеер запрашивает манифест потока один раз
при загрузке, и если расширение включилось позже, перехватывать уже нечего. В
окне для этого есть кнопка **«Обновить страницу»**.

Не помогло — откройте **«Диагностика»**. Страница показывает, на каком этапе
прерывается цепочка: работает ли перехват трафика, какие запросы распознаны и
по какой причине отклонены остальные.

## Состав

| Компонент | Назначение |
| --- | --- |
| `extension/background.js` | перехват сетевых запросов, учёт находок, постановка заданий |
| `extension/lib/detect.js` | классификация запросов: поток, фрагмент, посторонний ресурс |
| `extension/lib/hls.js` | разбор манифеста HLS: качества и длительность |
| `extension/lib/title.js` | заголовок страницы → имя файла |
| `extension/lib/store.js` | состояние расширения |
| `extension/lib/area.js` | выбор хранилища с проверкой работоспособности |
| `extension/lib/sightings.js` | журнал перехвата для диагностики |
| `extension/popup.*` | основное окно |
| `extension/options.*` | параметры |
| `extension/diag.*` | диагностика |
| `helper/host.js` | протокол связи с браузером |
| `helper/lib/ytdlp.js` | загрузка, прогресс, отмена, уборка временных файлов |
| `helper/lib/preview.js` | кадр из середины ролика |
| `helper/lib/cookies.js` | подготовка cookie для загрузчика |
| `helper/lib/paths.js` | поиск yt-dlp, ffmpeg и папки загрузок |
| `helper/lib/shell.js` | операции с файлами и папками |
| `helper/install.js` | установка и регистрация |

## Проверки

```
node tests/всё.js
```

Одиннадцать наборов, около полутора минут. По отдельности:

```
node tests/распознавание.mjs             классификация запросов
node tests/подсказки.mjs                 журнал перехвата и подсказки
node tests/хранилище.mjs                 выбор хранилища и запасной путь
node tests/сборка.mjs                    определение устаревшей версии
node tests/заголовки.js                  подготовка HTTP-заголовков
node tests/действия-с-файлами.js         удаление и уборка временных файлов
node tests/связь-с-помощником.js         протокол и загрузка звука
node tests/установленный-помощник.js     проверка установленного компонента
python tests/плейлист-без-расширения.py  нестандартные адреса манифестов
python tests/обложка-из-середины.py      кадр из середины ролика
python tests/живая-проверка.py           полный сценарий в браузере
```

Проверки в браузере выполняются невидимо. Чтобы наблюдать за ними, установите
переменную окружения `VIDEOLOV_SHOW=1`.

## Требования

- Windows 10 или 11
- Браузер на движке Chromium: Chrome, Chromium, Edge, Яндекс.Браузер
- Node.js 18 и новее, yt-dlp, ffmpeg

Поддержка macOS и Linux не реализована: установщик и файловые операции написаны
под Windows. Основная логика от платформы не зависит.

## Публикация в Chrome Web Store

```
node scripts/собрать-для-магазина.js
```

Собирает `build/videolov-<версия>.zip` — пакет для загрузки в магазин. Порядок
действий, готовые тексты карточки и обоснования разрешений —
в [docs/публикация-в-магазине.md](docs/публикация-в-магазине.md).

⚠ Опубликованное расширение получает **другой идентификатор**. После публикации
впишите его в `helper/allowed-extensions.json` и запустите установку загрузчика
заново — иначе расширение из магазина не увидит загрузчик.
